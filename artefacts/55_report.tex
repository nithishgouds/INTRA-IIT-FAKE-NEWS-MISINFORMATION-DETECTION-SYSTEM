\begin{abstract}
The rampant proliferation of deceptive content, political propaganda, and health misinformation on digital media poses severe existential risks to public trust, factual discourse, and decision-making. To assist journalists, content moderators, and trust-and-safety specialists, we present \textbf{TruthLens}---an end-to-end, interpretable, non-agentic Machine Learning platform engineered specifically for misinformation triage and auditing. TruthLens implements a multi-tiered pipeline coupling length-invariant linguistic and stylistic feature extractors with high-dimensional term-frequency representations, feeding a calibrated probabilistic classifier. Predictions are augmented with local feature attributions via SHAP (SHapley Additive exPlanations), an interactive regex-backed syntactic span highlighter, an empirical Bayesian Laplace-smoothed source credibility registry, and an auditable Human-in-the-Loop (HITL) case management dashboard. TruthLens operates in sub-second inference latency, provides dedicated multi-article batch analysis, and actively learns from reviewer feedback without destructively overwriting ground truth labels.
\end{abstract}

\section{Executive Summary \& Problem Formulation}
% -------------------------------------------------------------

\subsection{Background and Motivation}
Digital platforms generate millions of textual posts and news articles per minute. Human editorial review cannot scale to this volume, while opaque deep learning black-boxes fail to gain the institutional trust of professional fact-checkers. Content reviewers require transparent, calibrated decision-support tooling that not only flags suspicious claims with quantifiable uncertainty but also highlights the exact linguistic, stylistic, and source factors influencing each determination.

\subsection{Problem Statement \& Hackathon Scope}
The objective is to architect a robust, production-ready, non-agentic ML pipeline that analyzes submitted articles or social posts, predicts veracity probability ($P(\text{Misinformation})$), generates interpretable explanations, and provides complete Human-in-the-Loop workflows. In accordance with the Intra-IIT Hackathon 2026 guidelines:
\begin{itemize}[noitemsep]
    \item \textbf{Input Modality:} Textual articles/posts accompanied by source metadata, authors, and URLs.
    \item \textbf{Operational Paradigm:} Batch and single-item static processing (avoiding fragile live crawlers).
    \item \textbf{Explainability Requirement:} Granular local explanations via SHAP and interactive text highlight overlays.
    \item \textbf{Non-Binary Decisioning:} Explicit calibration with an `UNCERTAIN` classification tier.
    \item \textbf{Human-in-the-Loop:} Interactive feedback mechanisms that capture reviewer overrides for future retraining.
\end{itemize}

\subsection{Backend Architecture (FastAPI + SQLAlchemy)}
The backend service resides under \texttt{backend/app} and implements asynchronous REST routes adhering to OpenAPI / Swagger specifications:
\begin{itemize}[noitemsep]
    \item \texttt{POST /api/v1/analyze}: Processes single text payloads, returning full prediction vectors, confidence scores, SHAP explanations, and highlighted text spans.
    \item \texttt{POST /api/v1/feedback}: Records reviewer triage actions (\texttt{confirm}, \texttt{dismiss}, \texttt{relabel}) and rationale notes.
    \item \texttt{POST /api/v1/batch/analyze}: Ingests CSV files, running batch inference and computing aggregate dataset risk statistics.
    \item \texttt{GET /api/v1/sources}: Surfaces historical publisher profiles, verified official domains, and calculated reliability scores.
    \item \texttt{GET /api/v1/metrics}: Serves runtime confusion matrices, class-level precision/recall/F1 metrics, and failure analyses.
    \item \texttt{POST /api/v1/train}: Triggers model retraining utilizing both base datasets and human-reviewed samples.
\end{itemize}

\subsection{Database Persistence Schema}
Local state is persisted via SQLite through an ORM layer structured into five relational entities:
\begin{enumerate}[noitemsep]
    \item \textbf{Article}: Stores raw title, text, metadata (source, author, URL), ingestion timestamps, and dataset tags.
    \item \textbf{Prediction}: Retains calibrated probabilities ($P(\text{fake})$, $P(\text{real})$), categorical verdict, extracted linguistic vector, SHAP contributions, and review status.
    \item \textbf{Feedback}: Immutable audit trail linking reviewer actions, notes, previous model labels, and updated labels.
    \item \textbf{SourceCredibility}: Cumulative counts ($N_{\text{total}}$, $N_{\text{fake}}$, $N_{\text{real}}$) and updated credibility scores.
    \item \textbf{BatchJob}: Asynchronous batch execution metadata, file names, completion percentages, and summary counts.
\end{enumerate}

\section{Feature Engineering \& Preprocessing Pipeline}
% -------------------------------------------------------------

Misinformation often exhibits distinct statistical anomalies: extreme sentiment polarities, excessive punctuation, emotional appeals, and high lexical subjectivity. To prevent article length from introducing confounding biases, all extracted features in TruthLens are formulated as \textbf{length-invariant density ratios}.

\subsection{Preprocessing Mechanics}
The text preprocessor (\texttt{app/core/preprocessor.py}) performs systematic multi-stage cleaning:
\begin{itemize}[noitemsep]
    \item Normalization of HTML entities, stripping formatting tags while preserving casing metrics.
    \item URL and email tokenization, mapping URLs to domain representations for credibility lookup.
    \item Contraction expansion and punctuation preservation for lexical density counters.
    \item Optional stopword elimination and WordNet lemmatization for TF-IDF representations.
\end{itemize}

\section{Classification Model \& Probability Calibration}
% -------------------------------------------------------------

\subsection{Model Formulation: Hybrid Vector Pipeline}
TruthLens fuses high-dimensional n-gram semantic features with standardized continuous linguistic densities. Let text document $d$ have an extracted TF-IDF representation $\mathbf{x}_{\text{tfidf}} \in \mathbb{R}^{5000}$ (capturing word unigrams and bigrams with sublinear TF scaling) and a normalized handcrafted feature vector $\mathbf{x}_{\text{ling}} \in \mathbb{R}^{16}$. 

The combined feature representation is defined as:
\begin{equation}
\mathbf{z} = \left[ \mathbf{x}_{\text{tfidf}} \;\; \Vert \;\; \gamma \cdot \text{StandardScaler}(\mathbf{x}_{\text{ling}}) \right]
\end{equation}
where $\gamma = 0.35$ is the handcrafted scaling coefficient preventing high-dimensional TF-IDF features from drowning out dense linguistic markers.

Classification is performed via L2-regularized Logistic Regression optimized under class-balanced loss weighting:
\begin{equation}
P(y = \text{FAKE} \mid \mathbf{z}) = \sigma(\mathbf{w}^T \mathbf{z} + b) = \frac{1}{1 + e^{-(\mathbf{w}^T \mathbf{z} + b)}}
\end{equation}

\subsection{Non-Binary Decision Calibration}
Standard binary thresholding forces low-confidence borderline cases into definitive labels, inducing costly false positives in news rooms. TruthLens introduces an explicit \textbf{Three-Tier Decision Calibration Policy}:
\begin{equation}
\hat{y} = 
\begin{cases}
\text{\textbf{FAKE}} & \text{if } P(y = \text{FAKE} \mid \mathbf{z}) \ge \tau_{\text{fake}} \quad (\tau_{\text{fake}} = 0.65) \\
\text{\textbf{REAL}} & \text{if } P(y = \text{FAKE} \mid \mathbf{z}) \le \tau_{\text{real}} \quad (\tau_{\text{real}} = 0.35) \\
\text{\textbf{UNCERTAIN}} & \text{if } 0.35 < P(y = \text{FAKE} \mid \mathbf{z}) < 0.65
\end{cases}
\end{equation}
Confidence is explicitly normalized: $\text{Confidence} = 2 \cdot |P(\text{FAKE}) - 0.5| \in [0.0, 1.0]$.

\section{Explainability Layer \& Evidence Presentation}
% -------------------------------------------------------------

\subsection{SHAP Local Feature Attribution}
To guarantee full interpretability, TruthLens utilizes SHAP (SHapley Additive exPlanations) via \texttt{shap.LinearExplainer}. For any submitted article, the local prediction is decomposed into additive feature contributions $\phi_i$:
\begin{equation}
f(\mathbf{z}) = \phi_0 + \sum_{i=1}^{M} \phi_i
\end{equation}
where $\phi_0$ is the base expected value, and $\phi_i > 0$ indicates a feature shifting the prediction toward `FAKE` (rendered in warning red), while $\phi_i < 0$ shifts the prediction toward `REAL` (rendered in credible green).

\subsection{Interactive Text Span Highlighting}
In parallel with statistical SHAP weights, the prediction engine identifies exact character spans triggering cognitive bias alerts:
\begin{itemize}[noitemsep]
    \item \textbf{Sensational Spans (Red):} Clickbait markers (\textit{e.g.}, ``YOU WON'T BELIEVE'', ``SECRET EXPOSED'').
    \item \textbf{Unverified Hedge Spans (Amber):} Dubious sourcing markers (\textit{e.g.}, ``sources claim'', ``allegedly'').
    \item \textbf{Hyperbolic Casing Spans (Purple):} Unwarranted uppercase tokens ($\ge 3$ characters).
\end{itemize}

\section{Source Credibility Scoring \& Domain Verification}
% -------------------------------------------------------------

TruthLens enforces a strict architectural boundary: \textbf{Source credibility informs the reviewer context but is decoupled from pure textual feature extraction} to prevent circular bias.

\subsection{Empirical Bayesian Laplace Smoothing}
For any publisher domain $s$, credibility is tracked across historical evaluations using Laplace (add-$\alpha$) smoothing ($\alpha = 2$):
\begin{equation}
C(s) = \frac{N_{\text{real}}(s) + \alpha}{N_{\text{total}}(s) + 2\alpha}
\end{equation}
Prior to observing articles ($N=0$), the score defaults to an unbiased prior of $0.50$. As real or fake articles are confirmed, $C(s)$ asymptotically approaches empirical publisher reliability.

\subsection{Official Registry \& Publisher-Domain Mismatch Detection}
The engine cross-references domains against an authoritative verified registry:
\begin{itemize}[noitemsep]
    \item \textbf{Official Agencies ($C \ge 0.95$):} ISRO (\texttt{isro.gov.in}), NASA (\texttt{nasa.gov}), WHO (\texttt{who.int}), PIB (\texttt{pib.gov.in}).
    \item \textbf{Tier-1 Wire Services ($C \ge 0.92$):} Reuters, Associated Press, AFP, Nature, Science Magazine.
    \item \textbf{Known Hoax Networks ($C \le 0.15$):} InfoWars, NaturalNews, WorldNewsDailyReport.
    \item \textbf{Satirical Disclaimers ($C \approx 0.25$):} The Onion, Babylon Bee, The Fauxy (flagged as non-factual humor).
\end{itemize}
Furthermore, the engine compares claimed publisher strings with parsed URL hosts to detect spoofing or typosquatting attempts.

\section{Reviewer Dashboard \& Human-in-the-Loop Workflow}
% -------------------------------------------------------------

The user interface is designed for real-world trust-and-safety operations:
\begin{enumerate}
    \item \textbf{Triage Queue:} Prioritizes high-risk and uncertain content sorted by risk severity and submission recency.
    \item \textbf{Non-Destructive Feedback Protocol:} When a reviewer relabels or dismisses a model verdict, the original model prediction vector is preserved in the database alongside the new audit record (\texttt{reviewer\_label}, \texttt{reviewer\_note}, \texttt{reviewed\_at}).
    \item \textbf{Continuous Learning Integration:} Feedback records are aggregated into training datasets for scheduled retraining runs via \texttt{/api/v1/train}.
    \item \textbf{Batch Auditing:} Bulk CSV upload enables processing large volumes of news feeds with exportable CSV audit reports.
\end{enumerate}
